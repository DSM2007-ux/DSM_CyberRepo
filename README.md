# Cybersecurity Notes

My notes and write-ups from building practical cybersecurity skills alongside my degree at the University of Adelaide. Everything here uses free resources and is self-paced.

## About

I'm a first-year cybersecurity student. This repo follows a step-by-step skills plan, with a folder for each platform I use. I write everything in my own words and don't post passwords, flags or full solutions.
