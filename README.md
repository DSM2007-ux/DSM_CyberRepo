# Cybersecurity Notes

My notes and write-ups from building practical cybersecurity skills alongside my degree at the University of Adelaide. Everything here uses free resources.

## About

I'm a first-year cybersecurity student. This repo has a folder for each platform I use. I write everything in my own words and don't post passwords, flags or full solutions.

## Repo structure

| Folder | What's in it |
| --- | --- |
| [`bandit/`](bandit/) | OverTheWire Bandit: Linux command line and SSH basics |
| [`tryhackme/`](tryhackme/) | TryHackMe paths and room write-ups |
| [`portswigger/`](portswigger/) | PortSwigger Web Security Academy notes |
| [`home-lab/`](home-lab/) | VirtualBox lab with Kali Linux and Metasploitable 2 |

## How I take notes

For each level, room or lab I record:
- The goal, in my own words
- The commands or tools I used
- What I learned
- Where I got stuck

## Tools and platforms

OverTheWire, TryHackMe, PortSwigger Web Security Academy, VirtualBox, Kali Linux, Metasploitable 2, Nmap.
